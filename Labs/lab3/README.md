# Лабораторна робота №3 — Варіант 11: Облік завантаження каналів зв'язку

## Предметна область
Сервіс обліку вимірювань завантаження каналів зв'язку:
- **Категорії (`categories`)**: `internet`, `vpn`, `backup_link`
- **Поле `value`**: частка використання пропускної здатності каналу у відсотках (`float`, від `0.0` до `100.0` включно)
- **Одиниця вимірювання (`unit`)**: `percent`
- **Поріг (`threshold`)**: `70.0`
- **Статуси (`status`)**: `new`, `in_progress`, `done`
