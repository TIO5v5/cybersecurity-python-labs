## 2. Структура файлів варіанта
Вхідні та вихідні файли розміщені у папці data згідно з архітектурою проєкту:


```
Labs/lab2/
├── data/
│   ├── arp_audit.log               # Файл логів (генерується утилітою)
│   ├── arp_security_alerts.json    # Звіт про знайдені конфлікти (генерується утилітою)

├── __init__.py

├── README.md

└── task2.py
```

Утиліта приймає на вхід файл arp_table.csv.

## 3. Приклади запуску
Запуск Task 1 (Демонстрація ООП)
Демонстрація моделі користувача, безпечних сесій та системи аудиту:


```bash
python -m Labs.lab2.main demo
```

Запуск Task 2 (Аналізатор ARP-таблиць)
Виклик утиліти для перевірки ARP-таблиці та пошуку атак типу ARP-Spoofing:


```bash
python -m Labs.lab2.task2 --arp-file Labs/lab2/data/arp_table.csv --output-json Labs/lab2/data/arp_security_alerts.json --detect-spoofing --log-file Labs/lab2/data/arp_audit.log
```


## 4. Опис параметрів CLI (Task 2)
 - `--arp-file` (обов'язковий): Шлях до вхідного файлу ARP-таблиці (у форматі CSV).

- `--output-json` (обов'язковий): Шлях для збереження підсумкового звіту про знайдені конфлікти у форматі JSON.

- `--detect-spoofing` (опціональний): Прапорець (флаг). Якщо вказано, утиліта шукатиме дублювання MAC-адрес для різних IP (можлива атака Man-in-the-Middle).

- `--log-file` (опціональний): Шлях до файлу журналу (логування), куди записуватимуться всі події, попередження та помилки.

## 5. Поведінка при помилках
Файл не знайдено: Якщо переданий у --arp-file шлях є недійсним, утиліта виведе повідомлення про помилку [ERROR] Файл ... не знайдено і коректно завершить роботу без аварійного вильоту.

**Помилки валідації (Invalid syntax):** Якщо у вхідному файлі CSV відсутні необхідні поля (IP чи MAC-адреса) або вони не відповідають правильному формату (перевірка через регулярні вирази re), утиліта ігнорує ці рядки для подальшого аналізу. При цьому в консоль та у файл логів (якщо вказано --log-file) виводиться повідомлення рівня ERROR із зазначенням номера проблемного рядка та його вмісту.

**ARP-Spoofing (Конфлікти):** У разі виявлення однієї MAC-адреси, прив'язаної до декількох IP-адрес, утиліта реєструє подію рівня ALERT, виводить деталі в консоль та записує їх у JSON-звіт.
